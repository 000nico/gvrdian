before entering in VMX operation, we must discover if its supported.
Use CUPID and if CPUID.01H:ECX.VMX[5] = 1. Its supported

if supported, we need to enable it. Enable it through setting CR4.VMXE[bit 13] = 1

we should also check in the MSR IA32_FEATURE_CONTROL (3AH)
    - bit 0 is lock bit. should be 1. if its already 1, we should not write into this MSR
    - bit 1 enables VMXON in SMX. should be 1
    - bit 2 enabled VMXON outside SMX. should be 1

before executing VMXON. allocate a naturally aligned 4-kb region. This is called a VMXON region
The address of the VMXON Region (VMXON pointer) is provided in an operand to VMXON
