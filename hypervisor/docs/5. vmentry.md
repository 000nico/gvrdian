Event injection (of interrumpts and exceptions)
if the valid bit in the injected-event identification fild is 1, vm entry causes an event to be delivered 
vm entry delivers an injected event within the guest context established by vm entry, after the state is restablished (msr, guest state, etc)
  - if FRED transitions are not enblaed, the event is delivered using the vector in that field to select a descriptor in the IDT
  - if FRED transitions are enabled, the event is delivered using FRED event delivery (controlled by that MSRs)

in general, injected events are delivered exactly as if it had been generated normally

Details of event injection
The event injection process is controlled by the contents of the injected-event identification field. The injected event error code field, he injected event data field, and the vm instruction lenght field. An event being injectged never causes a VM Exit. It does not matter the configuration of your VMCS. For example, setting "NMI exiting"  to 1, does not make an injected NMI to cause a VM Exit
