A processor uses VMCS while in VMX operation
These manage transitions (VM Entries, VM exits)
These also manage process behavior in VMX Non-root

VMCS is managed by VMCLEAR, VMPTRLD, VMREAD, VMWRITE

A logical processor asssociates a region in memory with each VMCS. This is called the VMCS Region. The VMCS Pointer must be aligned on a 4kb boundary. bits 0:11 must be zero

VMLAUNCH, VMREAD, VMRESUME, VMWRITE operate only on the current VMCS

VMPTRLD operand is the VMCS pointer. After this instruction the VMCS is both active and ucrrent
VMCLEAR operand is also VMCS pointer. After this instruction that VMCS is neither active nor current. Sets launch state to "Clear"

in order to use VMLAUNCH. VMCS launch state should be "Clear". Then sets it to "launched"
in order to use VMRESUME, VMCS launch state shuld be "launched"

u can NOT modify launch state or read launch state through VMREAD or VMWRITE

FORMAT
    - Byte offset 0: bit 0:30 VMCS revision identifier, bit 31: shadow vmcs indicator
    - Byte offset 4: VMX Abort indicator
    - Byte offset 8: VMCS data


VMX Abort indicator should be filled with zero's

VMCS data is the part of CMS that actually control VMX non-root operation and transitions
