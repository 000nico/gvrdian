## Virtual-Machine Control Structure (VMCS)

The VMCS is a critical data structure used by the processor during VMX operation to manage VM entries, VM exits, and restrict processor behavior in VMX non-root operation.

### VMCS Region & Pointer
* **Memory Alignment:** Each VMCS is associated with a 4-KB region in memory (the VMCS Region). The VMCS pointer must be 4-KB aligned, meaning bits 0 through 11 must be zero.
* **Format Structure:**
  * **Byte Offset 0:** Bits 0–30 contain the VMCS revision identifier; bit 31 acts as the shadow VMCS indicator.
  * **Byte Offset 4:** The VMX abort indicator (must be initialized and filled with zeros).
  * **Byte Offset 8 onwards:** VMCS data fields.

### VMCS States & Instructions
Instructions such as `VMLAUNCH`, `VMREAD`, `VMRESUME`, and `VMWRITE` operate exclusively on the **current VMCS**.
* **`VMPTRLD`:** Takes a VMCS pointer as an operand, making that VMCS both **active** and **current** on the logical processor.
* **`VMCLEAR`:** Takes a VMCS pointer, sets its launch state to **"Clear"**, and marks it as neither active nor current, saving its state back to memory. (Executing `VMCLEAR` is mandatory before a VMCS can be loaded via `VMPTRLD` or launched via `VMLAUNCH`).
* **Launch States:** 
  * To use `VMLAUNCH`, the VMCS launch state must be **"Clear"** (subsequently transitions to **"launched"**).
  * To use `VMRESUME`, the VMCS launch state must be **"launched"**.
* *Note:* The launch state cannot be directly read or modified via `VMREAD` or `VMWRITE`.

### VMCS Data Layout
The VMCS data controls non-root operation and transitions, structured into several logical areas:
* **Guest-state area:** Processor state saved on VM exits and loaded during VM entries.
* **Host-state area:** Processor state loaded during VM entries.
* **VM-execution control fields:** Control processor behavior in non-root mode and determine what events trigger VM exits.
* **VM-exit control fields:** Manage behavior during VM exits.
* **VM-entry control fields:** Manage behavior during VM entries.
* **VM-exit information fields:** Receive detailed information describing the cause and context of recent VM exits (refer to Intel SDM Volume 3, Section 27.4+ for comprehensive field definitions).

Once the VMCS configuration fields are fully set up, you can proceed to execute `VMLAUNCH`.
