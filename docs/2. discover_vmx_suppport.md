## Enabling Intel VMX Operation

Before entering VMX operation, you must verify hardware support, configure control registers, check Model-Specific Registers (MSRs), and allocate a VMXON region.

### 1. Hardware Support Check
* **CPUID Verification:** Query the processor using `CPUID` with `EAX = 01H`. Check bit 5 of the `ECX` register (`CPUID.01H:ECX.VMX[5]`). If this bit is set to `1`, Intel VT-x is supported by the CPU.

### 2. Control Register Configuration (`CR4`)
* **Enable VMX Execution:** Set bit 13 of the `CR4` register (`CR4.VMXE`) to `1` to enable VMX operation.

### 3. MSR Verification (`IA32_FEATURE_CONTROL`)
Before writing configuration bits, inspect the `IA32_FEATURE_CONTROL` MSR (`0x3A`):
* **Lock Bit (Bit 0):** Must be `1`. If the lock bit is already set, you **must not** attempt to write to this MSR (doing so will trigger a General Protection Fault `#GP`).
* **VMXON Outside SMX (Bit 2):** Must be `1` to allow executing `VMXON` outside of Safer Mode Extensions (SMX).
* **VMXON Inside SMX (Bit 1):** Must be `1` if VMX operation is required inside SMX operation.

### 4. VMXON Region Allocation
* **Memory Alignment:** Before executing the `VMXON` instruction, allocate a naturally aligned 4-KB region of physical memory. This is designated as the **VMXON region**.
* **VMXON Pointer:** Supply the physical address of this region (the VMXON pointer) as an operand when executing the `VMXON` instruction.
